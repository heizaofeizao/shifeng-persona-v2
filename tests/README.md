# tests/ —— 测试资产

| 文件 | 用途 | 是否自动断言 |
|---|---|---|
| `golden_cases.md` | **LLM 输出质量用例**（A–K 组）。文体 / 立场 / 幽默 / 视角 / 台词纯净度**无法自动断言**，改动后由人工或 LLM 跑一遍 | 否（回归只检查它存在） |
| `archive/` | **历轮开发的过程记录**——各版本首战的收敛过程、golden run 结果（27/27 等）。不再参与 CI，仅供追溯"某条规则当初为什么这么定" | 否 |

```bash
python ../scripts/run_regression.py     # 82 项自动断言
```

> **分工原则**：能自动断言的进 `run_regression.py`；需要人判的进 `golden_cases.md`。两者都**不要**散写进 `modules/` —— 那里是给生成用的规则，不是测试台账。
