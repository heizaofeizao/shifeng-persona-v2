## 这是什么？

一个把石枫的公开言论蒸馏成**可运行 personas skill** 的东西。

它不靠背几十条金句硬装——那样装三天就露馅。它真的去读他 1686 条一手语料
（文章 61 / 回答 739 / 想法 884，2016–2026），用一套纯 Python 的本地检索层，
在你要发言前把**真实原话、时间戳、satire 标签**捞出来，再决定用多满的语气说话。

> 简单说：你问「石枫会怎么看 X」，它扮演石枫。

## 它凭什么不像 AI？

- **BM25 真实原话供给（P0）**：回答前先检索，引用带「原文片段 + 时间 + 出处」三件套，
  不凭印象编他的话。
- **立场置信度量化（P3）**：证据多硬，话就说多满。
  - `A 斩钉截铁`（"很明显""必须""归根结底"）
  - `B 正常陈述`
  - `C 留白`（"这个我不确定"）
  - `D 没谈过` → 不编造，落到现象层，台词外另附「交付注」
- **概念图谱推演（P4）**：395 个概念 / 303 条共现边，全从他原文统计。
  推演沿**他自己的概念拓扑**走——哈耶克旁边站的是米塞斯、罗斯巴德、柏克，
  不是 LLM 先验里那串 generic 保守主义。
- **去 AI 味（v2.2–v2.5）**：禁机械分层（"第一层/第二层"）、禁元叙事开场、
  禁元数据自陈。第一人称，从不汇报自己的档案。
- **文风指纹六层闸门（v2.7–v3.2）**：把「像不像」从形容词变成可比对的数字——
  **L1 标点**（他几乎不用叹号；回答里讲解冒号的中位数是 **0**）·
  **L2 句法**（长句逗号链、句末反问率 24%、招牌动作「引述包抄」）·
  **L2b 欧式长句**（关联词嵌套、的-定语链、名词化、分号长复句——**长度够≠肌理对**，
  逗号串短分句撑长的不算他）·
  **L2c 反口语化**（26 条硬禁句式逐条回语料核验；句尾语气词只禁 `呗啦哦哟咯嗯呀`，
  而 `呢` 是他的签名尾巴，必须放行）·
  **L3 篇章**（六种真实骨架、段落链式咬合、结尾禁止一切收束动作）·
  **L4 论战**（对上眼靶子时的德性攻击四拍）。
  交付前跑 `python scripts/style_check.py draft.txt`，**告警须归零**。

## 快速开始

```bash
# 1. 放进你的 skill 目录（WorkBuddy / 类 Agent 框架）
cp -r shifeng-persona-v2 ~/.workbuddy/skills/

# 2. 语料已经随包带了（corpus/final_corpus.jsonl，1686 条）
#    首次检索会自动建索引，缓存落在包外 ~/.workbuddy/cache/shifeng-persona-v2/

# 3. 试试三条流水线命令
python scripts/retrieve.py "全球化" -k 5
python scripts/stance_conf.py "死刑该不该废除"
python scripts/graph_walk.py "哈耶克" --path "孔子"
python scripts/style_check.py draft.txt        # 文风指纹自检，告警须归零
```

激活后直接说：「用石枫的视角聊聊 X」「石枫会怎么看 Y」「写一段杨佩帆式小说」。

## 🍷 一起来建设「古典美德」

做这个 skill 的过程，本质上是在回答一个问题：

> **当现代社会把德性拆成选项、把意义拆成流量，我们靠什么把人重新嵌回土地、家庭与责任？**

石枫的答案里有一句话我一直记得——儒家在这个节骨眼上的价值，
是「让悬空的自由重新嵌回具体的土地、家庭与责任里去」。

所以这份仓库**不是终点，是邀请**：

- 🛠️ **想加料？** 他的新文、新想法、新的反讽靶子，欢迎 PR 进 `corpus/` 或提 issue 讨论蒸馏口径。
- 🧪 **想改引擎？** 检索权重、置信度公式、图谱别名表都在 `scripts/` 里，随便调，调坏了有 `run_regression.py` 兜底。
- 📜 **想写长文？** `modules/style-longform.md` 等着你塞更多考据弹药。
- 🍁 **想建设古典美德？** 那更欢迎。我们不搞「进步主义」那套把人当可优化机器的叙事，
  我们聊秩序、聊德性、聊共同体、聊那些被绩效主义碾碎了却本该被守住的东西。
