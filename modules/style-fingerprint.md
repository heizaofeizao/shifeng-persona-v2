# 文风指纹（Style Fingerprint · P6）

> **加载时机**：任何要生成"像石枫"的文本时，**生成后必过** `scripts/style_check.py`；写长文前先扫本表。
> 本模块把"文风像不像"从形容词，变成**可比对的数字**。基线全部来自 1655 条正文实测（30638 句）。
>
> **本模块只覆盖 L1 标点层（表层）。** 句法层（句长/多逗号句/引述包抄）见 `style-diction.md`；篇章层（骨架/链式咬合/禁用结构）见 `style-structure.md`。三层齐过才叫"像"。

---

## 一、为什么需要它

"文风不够精确"的根因，通常不是"写得不好"，而是**跑成了另一个人的腔调**——一个"通用保守派评论员"：爱用感叹号、爱排比升华、爱破折号抒情、缺他自己的口癖。
形容词（"犀利""古雅""反讽"）无法校准这种偏移；**数字可以**。

## 二、分层基线（每千字命中次数；密度指标会被长文稀释，**必须先选对档**）

| 指标 | 短答 <300 | 中答 300~800 | pin 想法 | 长文 ≥800 | 说明 |
|---|---|---|---|---|---|
| 逗号 | 33.9 | **34.9** | 31.3 | 35.8 | 他长句多、逗号密（流畅长句，非短促断裂） |
| 句号 | 19.4 | 18.6 | 17.3 | 17.9 | — |
| 问号 | **6.90** | 4.13 | 5.84 | 2.18 | 反问极密，尤以短答为甚 |
| 叹号 | **0.31** | 0.23 | 0.25 | 0.15 | **几乎不用感叹号**（>1.0 即破功） |
| 破折号 | **0.48** | 0.79 | 0.80 | 1.20 | 回答里极少用——**别拿它抒情** |
| 省略号 | 0.51 | 0.43 | **1.01** | 0.37 | 想法里略多，问答里克制 |
| 引号 | **8.38** | 8.77 | 10.04 | 7.42 | 大量引述"所谓X / 标签 / 术语"，且用**全角“”** |
| **讲解冒号** | **1.23**（中位 0） | **1.38**（中位 0） | 1.32（中位 0） | 1.82（中位 1.6） | **见下节——回答里基本不用** |
| 句长中位 | 30 字 | **36 字** | 34 | 40 | 句子偏长，非格言体碎句 |
| 长句率(>40字) | 30.7% | 43.6% | 41.1% | 48.6% | 长句占三到四成 |

> **档位按字数自动选**（`<300 short · 300~800 mid · ≥800 long`）。**四段式回答落在 mid**——
> 拿 short 的尺量 mid 文本，会把它误判成"逗号超标、句子偏短"，这是最常见的误伤来源。

**第一人称**：全语料 我 6352 / 我们 2352 ≈ **2.7 : 1**——他有明确的"我们"维度（共同体、我们这代），不能通篇只有"我"。

### 2.1 讲解冒号：回答里基本不用（v3 新增）

语料实测**单篇分位**：

| 档 | p10 | p50（中位） | p90 |
|---|---|---|---|
| 短答 | 0 | **0** | 5.5 |
| 中答 | 0 | **0** | 3.6 |
| 想法 | 0 | **0** | 5.0 |
| 长文 | 0 | 1.6 | 3.8 |

**短答 82% 的篇目一个讲解冒号都没有**，中答的中位数同样是 0。所以像
「真要把左右说清楚，**绕不开两条：**人性上……」「这四个字**挺耐人寻味：**它预设了……」
这种"冒号引出讲解/定义/列举"的写法，**在回答里基本必错**——那是讲义腔，不是他。

他的冒号几乎只出现在三处（**都不算讲解冒号，不触发告警**）：
①引述提示（`他说：“……”`）②贴链接/贴标题（`就是这个： https://…`）③贴图说明。

**改法**：把冒号换成**句号断句**（`它预设了…`）或**逗号顺连**（`绕不开人性与认识论这两条，人性上…`）。
长文里可以少量保留（p50=1.6），但仍以 0~2 处为宜。

### 2.2 结尾闸门：讲完就停，不做首尾闭合（v3 新增）

语料实测**末句**特征：

| 档 | 末句为疑问 | 末句含升华/总结词 | 末句含祈使 |
|---|---|---|---|
| 短答 | 24.8% | **0.9%** | 10.4% |
| 想法 | 47.5% | **1.4%** | 7.3% |

他的结尾只有四种形态，**全是"讲完就停"**：

| 形态 | 真实语料样本 |
|---|---|
| 平实泄气 | 「所以这些回答看看就好。」「我认为他说的非常正确。」 |
| 狠话直落 | 「至于城市小资嘛，反正没有统战价值。哪一天被消灭了也是活该。」 |
| 疑问悬停 | 「……在一个基于无休止的个人解放原则的现代社会里，这种理想又如何才能实现呢？」 |
| 口语延续 | 「那现在嘛……反正就被刺激麻了，发泄情绪呗。」 |

**三种雷区（命中即告警）**：
1. **升华/总结收尾**——`总而言之 / 说到底 / 这才是 / 方为正道 / 让我们 / 我们应该`（基线仅 0.9%）。
2. **号召式「……吧」收尾**——典型如「先把那把歪掉的坐标扶正，**再谈转不转吧**」。这是作文式闭合，他从不这样收。
3. **末段回扣开头**——复现开头段的独特短语，做首尾呼应。他是"讲完就停"，不做结构闭环。

> 一句话：**结尾不许给答案、不许给号召、不许回扣**。要收就收在具体的话上，不落在"意义"上。

## 四、用法

```bash
# 默认按字数自动选档（short / mid / long）
python scripts/style_check.py draft.txt
# 手动指定分层
python scripts/style_check.py draft.txt --profile pin
python scripts/style_check.py draft.txt --profile long
# 管道
type draft.txt | python scripts/style_check.py -
```

输出含 `L1 标点 / L2 句法 / L3 篇章（含结尾闸门）` 三段，末尾给 `告警项 N 处` 与**具体哪几处**（讲解冒号会连上下文一起打出来）。**交付前要求 `N=0`**（或在交付注里说明为何保留某偏差）。

## 五、收敛示例（摘要）

**日本左右题四轮收敛（2026-09-19；逐版数据见 `tests/archive/test_japan_2026-09-19.md`）**：

| 层 | 初稿问题 | 修正 | 结果 |
|---|---|---|---|
| L1 标点 | 破折号 4.21、引号半角 | 破折号 → 0、引号改全角 | 告警 5 → 0 |
| L1 冒号 | 讲解冒号 3 处（`挺耐人寻味：…`） | 改逗号断句 / 另起一句 | 3 → 0 |
| L3 结尾 | 「……吧」号召式闭合 + 回扣开头 | 改"狠话直落"（"这年头最不缺的就是结论"） | 归零 |
| L2 句法 | 句长均 29.2——其实是**拿 short 的尺量 mid** | 补 mid 档后免于误伤 | 归零 |

> 通用教训：**先确认尺子对不对，再改稿**——误伤的告警会把你骗去改本来对的地方。

## 六、注意事项

- **先确认尺子对不对**——`<300 short · 300~800 mid · ≥800 long`；不传 `--profile` 会按字数自动选。**拿 short 量 mid 是最常见的误伤**。
- **引号用全角“”**：语料全用全角，半角 `"` 会被计为 0，且本身就不像。
- **叹号是雷**：他几乎不用；一旦出现 ≥2 处，基本可判定是"AI 抒情腔"。
- **冒号是雷**：回答里讲解冒号中位数为 0，写了就是讲义腔。
- **结尾是雷**：不许升华、不许号召、不许回扣——收在具体的话上，别落在"意义"上。
- 本表是**下限工具**，不是上限——0 告警只说明"不像别人"，不自动等于"像他"；观点与检索仍须走 P0/P3/P4。
