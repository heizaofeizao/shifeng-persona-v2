# 欧式长句 · 反口语化（Style — Euro-long & Anti-colloquial）

> **加载时机**：任何生成"像石枫"的文本，**与 `style-diction.md` 同时扫**。本模块是 L2 句法层的**第二个面**——
> `style-diction.md` 管"句子多长、怎么起笔收尾"，本模块管**"句子的书面性／学理性够不够"**。
> **2026-09-20 立**：触发原因是实测发现稿件「长复句率达标、但欧化装置全为 0，且口语味溢出」。
> 基线取自非虚构语料实测（1201 篇 / 111 万字，已按 `answer<300 / 300~800 / >=800 / pin` 分层）。

---

## 零、先分清两件事：**欧化 ≠ 作文腔**

这是最容易搞反的一处。`style-structure.md` 禁的是**作文腔机械分层**（首先／其次／综上所述），
**不是**禁关联词。两者形似而神反：

| | 作文腔（L3 已禁，语料≈0） | 欧化（L2b 必修，语料大量） |
|---|---|---|
| 形态 | `首先…其次…最后` | `尽管…但是…` / `无论…都` |
| 作用 | **横向**铺陈并列项（清单化） | **纵向**把主句挂到从句上（嵌套） |
| 后果 | 把文章写成 PPT | 把判断写成学理长句 |
| 语料实测 | ≈0~1.1/万字 | 关联配套 1.4~4.0/千字 |

> **去作文腔时最容易连欧化一起铲掉**——铲完就成了"短句格言体"，那是另一种不像。
> 判定口诀：**并列项用逗号，不用序号；从属关系用关联词，别省。**

## 一、缺口实测（为什么立这份规格）

拿 2026-09-20 四篇定稿（Q1~Q4，mid 档 379~503 字）与 mid 层基线对照：

| 欧化装置 | mid 基线 p50 / p90 | Q1 | Q2 | Q3 | Q4 | 结论 |
|---|---|---|---|---|---|---|
| 关联词配套（千字） | 1.44 / 4.05 | **0** | **0** | **0** | **0** | ❌ 全军覆没 |
| 的-定语链（千字） | 0 / 3.21 | **0** | **0** | **0** | **0** | ❌ 全无 |
| 名词化（千字） | 0 / 3.03 | 0 | 0 | 2.64 | 0 | ⚠ 偶发 |
| 分号长复句（千字） | 0 / 1.82 | **0** | **0** | **0** | **0** | ❌ 全无 |
| 长复句率（>60字） | 18.2% / 40% | 18.2% | 14.3% | 20.0% | 20.0% | ✅ 达标 |

**读法**：句子**长度**够了，但**肌理**不对——他是靠"关联词嵌套 + 长定语 + 名词化"把句子撑长的，
稿子是靠"逗号串短分句"撑长的。**长度相同，句法血统不同**，所以读起来像中文评论员而不是他。

## 二、六种欧化装置（每条含实测密度 + 真实范例）

### 装置 1 · 的-定语链（名词短语前置多层修饰）
**实测**：1.26/千字，35.5% 的篇目出现。**这是最直接的欧化指纹**——一个中心词前挂两三层"…的…的"。

> 「但奥派思想**对人的行为研究的**重视、**对实在论的**坚持、**对基于财产所有权的朴素传统经济伦理的**认同都给我非常深的启示」
> 「我顶着学校繁多的课业和严重的抑郁情绪读了大量**我觉得可能有用的**书籍」

**操作**：写完一个抽象名词（重视／坚持／认同／批判／态度／可能性），检查它前面有没有"对…的"或"…的…的"修饰层。
若只有光秃秃一个名词 → 补一层定语。

### 装置 2 · 关联词配套（他的**纵向**推论引擎，命中越多越像）
**实测密度**（每千字）：`如果…就` 0.38 · `当…时` 0.47 · `无论…都` 0.15 · `虽然…但` 0.19 ·
`不仅…而且／也` 0.19 · `尽管…但` 0.14 · `即使…也` 0.15 · `因为…所以` 0.04 · `之所以…是因为` 0.03

> 「**无论**动机好坏最终**都**只会得到弱肉强食的无序状态」
> 「社会与共同体**不仅**为人类提供了起码的安全与生存来源，**也**使人的完善与发展成为可能」
> 「我们**之所以**持续输掉这场战役，**是因为**我们仍然未能看清这一切是如何相互关联的」

**操作**：**前件必须显式出现**。中文习惯是"动机好坏都会…"（省掉"无论"），他偏要把关联词写出来。
mid 档每篇**至少 1 处**配套，长文每千字 ≥1.4。

### 装置 3 · 名词化抽象（把动词/形容词提成名词）
**实测**：`…性` 0.68/千字 · `…化` 0.48/千字 · `可能性/必要性/重要性/正当性` 0.21/千字 · `对…的X` 0.18/千字

> 「智识的**诚实性**」「人的**完善与发展**」「自发秩序」「**正当性**基础」「秩序的**不可复制性**」
> 「正因为**我对美国与世界政治的关注**是从桑德斯开始的」

**操作**：口语会说"社会要好起来""这事做得对不对"；他写"社会的**完善**""**正当性**"。
把句中的谓语动词**提成名词**再挂上定语，是最省力的欧化动作。

### 装置 4 · 关系化定语（"那些…的人／一种…的N"）
**实测**：0.40~0.96/千字，18.8~29.6% 篇目。
> 「他坚决地将**那些**决定美国外交政策、至今依然如此的有教养、受过良好教育的精英阶层**而言**…」
> 「**一种**共识逐渐**形成**」「**一个**连大年夜都懒得回家、待在出租屋里点外卖刷手机**的人**」

**操作**：写到某类人时，不要写"精英""大V"，写"**那些**…的**人**"——中心词后置、修饰语前置。

### 装置 5 · 分号长复句（两段 25 字以上分句对举）
**实测**：0.47/千字，20.6% 篇目。**分号是他的"对举"武器**，用得多而稳。
> 「在进步主义的旗号下打击一部分寡头，在许多传统领域维持市场竞争，维护小生产者**；**而在新国家主义的旗号下对那些更加重要的行业…施加控制」

**操作**：遇到两个平行长分句，**用分号断开，不要用句号**——句号会把欧化复句剁成中文流水句。

### 装置 6 · 破折号插入成分（书面补充，与口语插话不同）
**实测**：0.12/千字，4.7% 篇目。低频但**标志性极强**，用准了很像。
> 「也相信一定程度的道德保守主义对维护自由有益无害——**大体上这也是罗斯巴德、霍普等人的观点，更不用说同时作为古典自由主义和保守主义伟大先驱的托克维尔了**。」
>
> ⚠ 与 L1 破折号基线（短答 0~1.2/千字）**不冲突**：那是密度上限，这是**用法**要求——破折号后面要接**完整的书面从句**，不是口语插话（"——真的"）。

## 三、正面范例（他本人的欧式长句，已剔译稿核验）

> 「我当时信守着洛克式的对绝对个人自由的信念，但也相信一定程度的道德保守主义对维护自由有益无害——大体上这也是罗斯巴德、霍普等人的观点，更不用说同时作为古典自由主义和保守主义伟大先驱的托克维尔了。」（96 字）

> 「我们希望建设这样一个社会：它保留了市场经济、科学技术与现代自由主义为我们提供的许多成果，但又扎根于深厚的历史、文化与民族传统之中，有着坚实的社会纽带、具备充分约束力的公序良俗与生机勃勃的自组织。」（97 字）

> 「保守主义意味着将社会变革转化为社会革新，没有秩序的变革无论动机好坏最终都只会得到弱肉强食的无序状态。」（50 字，**含"无论…都"配套 + "没有秩序的变革"长定语**）

**读法**：三句都不是"把短句用逗号串长"，而是**一个主句 + 层层挂上的修饰/让步/条件从句**。

## 四、改写示范（口语流水句 → 他的欧化长句）

| 口语流水句（现状） | 欧化长句（目标） | 用了哪条装置 |
|---|---|---|
| 你去那几个问题底下扫一眼就明白，广大理工科群众连…都没共识。 | 「只要**把这几个问题底下的回答通读一遍**，就会看到**一种**耐人寻味的**现象**：广大理工科群众连…都未能达成共识。」 | 2 关联配套 + 4 关系化 |
| 反正拆到最后，孤零零一个你，才是最好卖的东西。 | 「**当一切中间层都被碾平之后**，剩下的**无非**是**一个只对自己负责的原子化个体**，而**恰恰是这种孤立状态**，才是最便于被反复收割的**位置**。」 | 2 当…之后 + 3 名词化 + 1 的链 |
| 这算哪门子自由主义。 | 「**如果**这也能叫自由主义，**那么**自由主义的**内涵**就只剩下**对一切共同体约束的拒斥**了。」 | 2 如果…那么 + 3 对…的X |

> 注意：欧化**不取消**他的口癖（无非／罢了／其实／毕竟）。**口癖是词汇层的，欧化是句法层的，两者叠加才像。**

## 五、量化目标（mid 档 / 300~800 字，四段式回答）

| 指标 | 下线（必达） | 上线（勿超） | 语料 p50 |
|---|---|---|---|
| 长复句率（>60 字） | **≥ 12%** | ≤ 55% | 18.2% |
| 关联词配套密度（千字） | **≥ 1.0** | ≤ 6.0 | 1.44 |
| 的-定语链密度（千字） | **≥ 0.6** | ≤ 6.0 | 0 |
| 名词化密度（千字） | **≥ 0.8** | ≤ 6.0 | 0 |
| 分号长复句 | **≥ 1 处**（全文） | — | 0 |

> 上限定得宽（p90 的 1.5~2 倍）是刻意的：**欧化过度会变成翻译腔**，但"翻译腔"比"口语腔"离他更近。
> 宁可略过他，不要欠他——**这是他文风里最容易欠的一维**。

### 6.2 句尾语气词硬禁：`呗 啦 哦 哟 咯 嗯 呀`
**实测**：全语料句末语气词共 832 次（占 3.42%），其中 **`呢` 独占 585 次（70%）**——`呢？`是他的**签名反问尾巴**。
但 `呗(11) 啦(7) 咯(2) 呀(2) 哦(1)` 合计 **23 次** ≈ 0。

> **允许**：`呢`（签名）· `吗`（531 次）· `吧`（107 次）· `啊`（69 次）· `嘛`（48 次）
> **禁止**：`呗 啦 哦 哟 咯 嗯 呀`
>
> 别一刀切禁语气词——**禁错等于把他最像的地方改掉**。

## 七、自检清单（本模块）

- [ ] **关联词配套 ≥1 处**：`尽管…但` / `无论…都` / `不仅…也` / `之所以…是因为` / `如果…就` / `当…时`，**前件不许省**。
- [ ] **的-定语链 ≥1 处**：抽象名词前挂"对…的"或两层"…的…的"。
- [ ] **名词化 ≥1 处**：谓语提成名词（…性 / …化 / 可能性 / 正当性）。
- [ ] **分号长复句 ≥1 处**：两个平行长分句用 `；` 对举，**不许用句号剁开**。
- [ ] **长复句率 ≥12%**（>60 字）。
- [ ] 硬禁句式 **0 命中**（§6.1 全表）。
- [ ] 句尾语气词只用 `呢/吗/吧/啊/嘛`，**零 `呗啦哦哟咯嗯呀`**。
- [ ] 口语词总密度 **≤3.6/千字**。
- [ ] 跑 `python scripts/style_check.py <draft>`，**L2b 段告警 = 0**。
