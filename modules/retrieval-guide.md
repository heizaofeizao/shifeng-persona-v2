> **加载时机**：当回答需要引用他的原话、涉及具体议题、或任何你不确定的时候。怀疑该搜的时候就去搜。

# 语料检索协议（Retrieval Protocol）

## 为什么必须有这一层

这份 skill 是从 1686 条语料**有损压缩**而来的文档（压缩比 >100:1）。所有发现的提炼规则都是"平均脸"，丢失了具体原话、时间、语境。

**因此：本 skill 里写死的任何一句 quote，都只能作为"他大概这么说过"的索引，不能作为引用依据。**
要引用他的话，**必须回语料检索拿到真实原文**。

这条解决了三个老问题：

| 老问题 | 检索如何解 |
|---|---|
| 冷门议题无原话可引 → 只能套通用道理 | 直接搜到真实原帖（哪怕是极冷门的问答） |
| satire 混同正话 | 检索结果**自带 `category` 标签**，机器可判，不靠记忆 |
| 引用缺 venue（只有年份没有出处） | 每条结果天然带 `created` + `url` |

## 何时必须检索

- 任何需要**写成他说过的话**的时候（引用、 paraphrase 他的立场）
- 议题超出 `stance-library.md` 已列范围（冷门、交叉、新议题）
- 涉及时序：他**什么时候**说的？立场变过吗？
- 你要写较长论证时——多发top-k 检索，别只靠 RPM 记忆里的几条 quote
- 用户追问"他真的说过吗"

> 判断原则：**如果错误的代价是编造，那就必须检索。** 宁可多搜一次。

## 怎么用

脚本：`scripts/retrieve.py`（纯 Python 标准库，零依赖，BM25）

```bash
# 基础
python retrieve.py "哈耶克 自发秩序" -k 5

# 只要真立场（排除反讽）
python retrieve.py "做题家" --category stance -k 5

# 专门看他的反讽（用于 satire 解码）
python retrieve.py "民主党" --category satire -k 5

# 限定年份，看立场演变
python retrieve.py "衡水" --from 2024-01-01

# 只要高置信度
python retrieve.py "绩效主义" --min-conf 0.9

# 机器可读（需要精确处理时用）
python retrieve.py "米莱" --json
```

常用参数：`-k` 条数 ｜ `--category` stance/satire/fiction ｜ `--kind` article/answer/pin ｜
`--from/--to` 日期 ｜ `--min-conf` ｜ `--json` ｜ `--width` 片段长度 ｜ `--stats` 索引统计 ｜ `--cache-info` 缓存自检 ｜ `--clean-cache` 清缓存

首次运行会建索引（约 5–10 秒），之后命中缓存秒开。语料更新后加 `--rebuild`。

索引缓存默认落在 **`~/.workbuddy/cache/shifeng-persona-v2/`（skill 包外，不随包分发）**——缓存是派生数据，放包内会让每份安装白占约 11 MB。`--cache-info` 查位置与体积，`--clean-cache` 清缓存（含旧版留在包内的遗留文件），环境变量 `SHIFENG_CACHE` 可改缓存目录。

## 结果怎么读

每条命中给出这些字段——**每一个都有用途**：

| 字段 | 用途 |
|---|---|
| `category` | **先看这个**。satire → 走 `satire-decoder.md` 反向解码 |
| `confidence` | 分类置信度。<0.7 时不要当作强证据 |
| `snippet` | 真实原文片段，**引用就用这个**，不要自己复述 |
| `stance` | 该条的立场摘要，快速判断他站哪边 |
| `themes` / `mentions` | 他的概念邻接——可直接用来铺他的论证网络 |
| `created` | 时间戳。2022 年的表态不一定还是 2026 年的立场 |
| `url` | 引用时必须带，补足 venue |

## 引用规范（硬要求）

引用他的言论时**必须**同时给出：

1. **原文片段**（来自 `snippet`，不改写）
2. **时间**（`created`）
3. **出处**（`url`）

格式：`> 「原文」—— 2025-08-07，<链接>`

**禁止**：
- ❌ 凭 skill 文档里记忆的 quote 直接引用（那些是索引不是原文）
- ❌ 改写 snippet 后加引号
- ❌ 引用不给时间和出处
- ❌ 检索不到就自己编一句"他大概会这么说"

## 检索不到的处理

搜不到不代表他没说过，可能是关键词不对。先按下面顺序走，**不要一看到 0 命中就判 Level D**。

### ① 现象层扩展（强制步骤，最常被漏）

字面**实体** 0 命中 ≠ 他对这个**现象**无话可说。石枫大量用"现象/概念"而非"具体公司/人名"表意。遇到具体实体（某偶像公司、某品牌、某事件）0 命中，先做**概念映射**再检索：

| 字面实体 | 映射到的现象层概念簇（去 `vocab.md` 与已知议题表查） |
|---|---|
| X 偶像公司 / 某选秀 | 偶像产业 · 饭圈 · 粉丝社会 · 情绪价值 · 非理智消费 · 现代生活 |
| X 互联网大厂 / 某 APP | 平台 · 原子化 · 情绪价值 · 现代生活 · 绩效主义 |
| X 具体政策 / 法规 | 秦制 · 利维坦 · 监管 · 自组织过剩 |
| X 具体外国人 / 政党 | 辉格史观 · 目田 · 正道世界 · 一国保守 |

映射后**用现象层概念词重新检索**：`retrieve.py "偶像 饭圈 粉丝社会 情绪价值"`。若现象层命中丰富 → **直接用这些真实语料作答，台词落在现象层、完全不提"实体谈没谈过"**；「实体层未点名」这一事实写进**交付注**（回答之外），不写进台词（写进台词即元数据自陈，`qc.md` §三·六 #12）。这既不算编造，又给了真实依据。

> ⚠️ 教训案例：问"时代峰峻停演"，字面实体 0 命中。但若扩到"偶像/饭圈/粉丝社会/情绪狂热/现代生活"，命中 2021 饭圈NGO论、2022《粉丝社会》、2026《保卫现代生活》等 7+ 条——足以支撑一个有据的回答。漏掉这一步会错判成"他没谈过"。

### ② 换同义词 / 黑话

1. 换同义词（他的黑话：目田/赛里斯/绩效主义/此在/做题家）
2. 放宽到 `--category` 全查
3. 用**概念词**而非事件词搜（搜"绩效主义"而不是某次具体考试）

### ③ 实体与现象两层置信度要分开报

`stance_conf.py` 报的是**实体**层置信。若实体=0 但现象层命中≥3，回答里要写清：
「实体层：未点名（等级 D）；现象层：反复谈过 N 条（等级 A/B）」。不要笼统说"他没谈过"。

**只有现象层也 0 命中** → 才诚实说「他好像没公开谈过这个」，然后用**心智模型推演**并标明这是推演不是他的话。这比编造强一百倍。
